# 図と段階表示の再設計

2026-09-14。対象は14種類の流れ・関係図と、発表中に注目箇所を送る操作。一般記事の図には適用しない。本番への投稿・反映は行っていない。

## 変えたこと

図全体を空き幅へ自動拡大していたため、同じ資料でも図によって文字の大きさが変わっていた。図の領域を固定し、主語32px、説明・条件20px（日程の項目名28px）を保って配置する。工程は番号と余白、状態は細い輪郭、分岐は条件を線から離して示す。接続線は箱から垂直に出入りし、箱と文字を避ける。全図へ同じ箱と装飾を当てる作りを廃した。

元のMermaid文をそのまま正本に残し、対応形式だけを閲覧時に組み直す。独自装飾などを含む未対応の構文は元の描画に戻し、意味や原文を捨てない。集合・象限は既存の図データを引き続き使う。

読む画面に「順に見る」を置き、発表画面には段階名・現在地と「前へ／次へ／全体」を表示する。複数の対象を同時に強調できる。段階ごとの補足の長さにかかわらず紙の大きさを固定し、強調時に文字サイズ・太さ・改行を変えない。

図の解釈は固定版の[Mermaidの仕様](https://mermaid.js.org/config/schema-docs/config-defs-flowchart-diagram-config.html)に従う。操作の考え方は[Keynoteのオブジェクト単位のアニメーション](https://support.apple.com/guide/keynote/animate-objects-on-a-slide-tanf96d92cb6/mac)を参考にし、この資料形式の単一の前後操作へ統合した。

## 余白の追加修正

箱なしの工程・入出力・因果は、見えない箱の余白を除き、番号・主語・説明の左端を見出しにそろえる。列を横いっぱいへ伸ばさず、240pxを上限とする列と短い接続線でまとめる。番号から主語までの行間隔は12px、主語から説明は16px。短い条件文は、接続先との空きも含めて幅を確保し、4文字を2行に割らない。

発表の操作欄は紙の直下12px、補足は操作欄の直下12pxに置く。全段階の最大高さは紙の倍率を固定するためだけに使い、補足の位置には現在の操作欄の高さを使う。別の段階に長い見出しがあっても、現在の段階へ100px以上の空きを持ち込まない。

全検査6,496項目が成功。2ブラウザ×2画面幅×4段階で紙の位置・大きさが一定、紙と操作欄の間隔12pxを確認。図14形式と改訂見本3枚も再確認し、文字の重なり・はみ出し・線の横切り0。最終の短い条件文は1行になっていることを目視した。
