# 検査のための材料（fixtures）

ここに置いてある HTML は **検査のための材料であって、ページの正本ではない**。
正本は Supabase の `pages` / `page_revisions`。

## なぜここに置くか

検査表は「配信のときに差し込むもの」や「本文の数え方が
サーバー側とブラウザ側でそろっているか」を、**本物の HTML を通して**確かめる。
そのために実物大の材料が要る。

その材料を保管庫から取りに行かせると、**検査のたびに本番の鍵が要る**ようになる。
検査は鍵の無い場所（他人の手元・CI）でも走れないと番人にならないので、
材料だけをここに写して持ち歩く。

## 触るときの決まり

- ここを直しても、配信されるページは 1 文字も変わらない。
  ページを直したいときは投稿（`bin/pages-publish`）から入る
- 検査が見ている性質（本文の数え方・差し込みの入り方）を確かめたいだけなので、
  中身が最新のページと一致している必要はない
- 枚数を減らさない。検査表の項目数は控え（`tests/checks/baseline.json`）と
  突き合わせていて、**減ったら失敗する**
