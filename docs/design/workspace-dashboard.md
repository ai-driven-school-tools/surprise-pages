# 個人ワークスペース

会社のアカウントで開いたトップは、台帳上の作成者が本人の資料を表示する。共同編集は有効な共同所有だけで、管理者特権は含めない。会社の資料には現在閲覧可能な行だけを渡す。共有範囲・編集・共有設定・申請対応の判定は既存の権限処理を通す。

## 構成

- `/` 自分の資料、`/favorites` お気に入り、`/library` 会社の資料。
- `/activity` 最近見た資料と自分のコメント。匿名の公開資料向け利用も残す。
- `/create` 3形式の共通入口。文書と図解はAIへの依頼案内。`/decks/create` は既存の作成画面。
- `/settings` アカウント・外観・閲覧記録・投稿環境・マイテーマ。`/devices` と `/sharing` の既存リンクを維持。
- 本文・スライドの表現には管理画面の外観設定を適用しない。

## 追加した保存情報

`page_catalog` は資料・版・分類規則の版に対応した再生成可能な索引。本文の正本や権限判定には使わない。保存成功・同内容の再投稿・配信修復で分類を補完し、分類の書込失敗だけで本文保存の結果を失敗にしない。読み込み失敗や版不一致は形式未確認として扱う。

`page_favorites` と `workspace_preferences` は本人のアカウントに紐付く。ブラウザから保存先へ直接アクセスさせず、画面のログインから本人を確定する。APIに渡したアドレスで本人を指定できない。お気に入りの追加・削除は現在の閲覧権限を通す。

一覧の本文は取得しない。資料とお気に入り・共同所有は分割取得し、形式は40件ずつ取得する。画面は50件ずつ表示し、検索・絞り込み・並び替えは受け取った閲覧可能な全行が対象。検索条件はURLに、スクロール位置は内容を含まない数値だけをセッション中に保持する。
