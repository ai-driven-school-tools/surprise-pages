# 63形式の完成例と媒体配信の修正

2026-09-14。全形式のレビューで見つかった50形式の問題を、見本の内容と共通描画の両方で修正した。

## 修正内容

- 形式の説明を大見出しへ反復する作りをやめ、架空ASTER NOTEの判断と根拠を各枚の主役にした。比較、料金、担当期限、評価、リスク、確認表は用途固有の列と内容を持つ。採用根拠・未達・最優先・未完了を、文字の主従で示す。
- 無関係なオフィス写真を廃し、入力前後、整理、共有、検索などの異なる画面を生成する。人物は役割と責任を主役にする。動画は15秒の操作イメージ、音声は架空の利用者の声を明示した合成音声。字幕と全文を付ける。生成物はGitへ入れず、生成元だけを管理する。
- グラフの名称、分母、期間、単位を明記。流量の接続を検証し、実績と予測、予測幅、増減と総額を別々に正しく描く。目標は共通なら1本だけにし、地域の名前を二重に描かない。図・出典・脚注が残り高に収まる共通配置へ変更した。
- 並べ替え後の点も永続IDから強調する。印刷中は図の強調も解除し、印刷後に発表状態を復元する。資料内の参照リンクは、安定した枚のIDから現在の枚番号へ変換する。
- 非公開素材はサイズと強い目印を先に確認し、要求された範囲だけをストリームで返す。HEAD、206、416、If-Range、304に対応。閲覧の関門を通し、本文全体をメモリへ読まない。過去素材の取得失敗を「存在しない」と読み替えない。
