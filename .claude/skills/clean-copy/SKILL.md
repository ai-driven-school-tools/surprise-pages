# 手順は同じフォルダの `手引き.md` にある

この SKILL.md には手順を書かない。**同じフォルダの `手引き.md` を Read で全文読み、そこに書かれた手順だけに従う。**
一部だけ拾い読みして進めない。

- このスキルは、どのフォルダからでも使える。投稿・取り寄せの道具は、このスキルが入っている配布物のフォルダ
  （`<リポジトリ>`。この SKILL.md の実体から 3 つ上）の `bin/pages-publish.mjs`（`node <リポジトリ>/bin/pages-publish.mjs …` で呼ぶ）。
- 投稿先は自分のサイトだけ。鍵（ログインの控え）の中身を画面やチャットに出さない。
- `手引き.md` が見つからないときは、配布物が欠けている。推測で進めず、そう伝えて止まる。
