# 清書の見た目は、開いたときに付ける

清書（clean-copy）のページとリポジトリの文書は、**字は保存したときのまま、見た目は開いたときのいちばん新しいもの**で出す。
正本は `src/lib/settings/clean-copy-look.ts`。検査は `tests/checks/check-clean-copy-look.mjs`。

## なぜ

清書の変換器は、見た目の指定（Tailwind のクラス）を見出し・段落・箇条書きの 1 つずつに書き込む。
ページは保存したあと書き換えない（版は追記専用）ので、スキルで見た目を直しても過去のページには届かず、
作った日ごとに見た目がばらついていた（2026-10-08、薄い灰色の地の文・上端の青い線のまま出ていた）。

```
Before
  保存した本文 = 字 ＋ 組んだ日の見た目 → そのまま配る → 作った日ごとに見た目が違う

After
  保存した本文 = 字 ＋ 組んだ日の見た目 ＋ どの見た目で組んだかの印
  配るとき     = 印から元の変換表を引き、要素の役目ごとに、いまの見た目へ付け替える
```

## 何を付け替えるか

| 対象 | どうするか |
| --- | --- |
| 本文の要素のクラス | ページの印（`main` の `data-clean-copy-look`）から組んだときの変換表を引き、クラスから要素の役目（段落・見出し・箇条書き…）を逆に引いて、いまの変換表のクラスへ。印の無い昔のページは、印を付ける前に配った変換表すべてから引く。同じクラスが別の役目を指すものは引かずに残す |
| 清書の文字組み・表示形式の指定（`<style data-clean-copy-style>`） | いまのものへ置き換える。無ければ head の終わりに足す |
| 額縁（色の名前を決める style・body のクラス） | いまの額縁のものへ置き換える。body のクラスは、過去の額縁が書いたものと同じときだけ |

触らないもの:

- **字。** 触るのはクラスの値と head の style だけなので、コメントの引用の位置（本文の文字数）・書き出し・索引は変わらない
- 保管庫の HTML（投稿・直す・取り寄せの口は、保存されたままを使う）
- 清書の印（`data-clean-copy-document`）の無いページ（図解・スライド）。1 バイトも変えない
- 知らない印のページ（Pages の写しより新しいスキルで組んだもの）。古い見た目へ戻さない
- 機械で変換する前（2026-09-06 より前）に AI が書いた清書。印が無く、決まった変換表で組まれていない

配信の照合（ETag）と描画前の指定の控えは、写しを上げると変わる（`CLEAN_COPY_LOOK_STAMP`）。

## 見た目を変えるときの流れ

1. スキルの置き場（`.claude/skills/clean-copy`）で `cleancopy/convert.py` の変換表・文字組みの指定か、額縁（`_shared/references/base.html`）を直して取り込む
2. 見た目の一式（`src/lib/settings/clean-copy-look.generated.json`）を、同梱のスキルから書き出し直す（`python3 .claude/skills/clean-copy/scripts/run.py look` の出力と額縁の印。手で書き写さない）。一式には過去に配った変換表もすべて入る
3. PR を出して取り込む。過去の清書ページも、公開した日から新しい見た目で出る

写しが古くなっていないかは `tests/checks/check-clean-copy-look.mjs` が見る。

## 正本

- 見た目の一式の正本はスキルの `look()`（`python3 run.py look` で JSON に出る）。Pages は写しを読むだけで、値を書き写さない
- 変換器が変換表の値に字を足して書く形（引用の箱の ` text-center`）だけは、`src/lib/settings/clean-copy-look.ts` の `COMPOSED` が変換器と同じ字面を持つ
