ここから先で、この仕組みをひとつずつ解説していきます。

Pages とは — 何がうれしいのか

Pages は、社内の図解やレポートを 1 つの場所にまとめて置いておく掲示板です。1 件が 1 枚のページになり、それぞれに URL が付きます。読む人はそのリンクを開くだけです。

いちばん大きな違いは、ページを手で作らないことです。作りたい中身を Claude Code（会話でコンピュータの作業を頼めるツール）に話しかけると、見出し・図・表まで組み上げた 1 枚ができ、そのまま投稿されて URL が返ってきます。

話しかけるところ
先週の勉強会の議事録、これをページにして社内に共有して
決まったことを 4 枚のカードにして、担当と期限を添えました。投稿しました。
https://pages.example.com/i/minutes/2026-08-05
メッセージを入力

「きれいな資料を作る時間がないから、とりあえず箇条書きで Slack に流す」ということが減ります。うれしいところは大きく 5 つです。

社内のものは社内で止まる

既定のページには入口に門があり、会社の Google アカウントで入った人しか開けません。リンクが外に流れても、中身は見えません。

中身を渡せばページになる

見た目を整える作業がまるごと要りません。話しかければ、図・表・カードに組み直したうえで投稿まで進みます。

気になった一文に直接書ける

文章をドラッグで選んでコメントを付けられます。「3 段落目の後半のところですが」と場所を説明する手間が消えます。

直した記録が自動で残る

いつ誰が直したかの一覧が付きます。版を選ぶと、足した文字に下線・消した文字に取り消し線が付いた形で違いが見えます。

Slack に貼るときれいなカードになる

ページから直接チャンネルを選んで投稿できます。社内限定のページは、リンクを貼っても見出しや要約が展開されません。ログインしていない人の画面に中身が出てしまわないようにしてあります。

ここがポイント

Pages が引き受けるのは「見せる」ところです。何を書くかを考えるのはあなた、読みやすい 1 枚に組み立てて配るところは仕組みの側。言葉にした瞬間に共有できる状態になっているのが、いちばんの違いです。

使い始め方 — 2 通り

ページを作る力（スキル）は、Claude Code に後から足す部品として配っています。入れ方は 2 通りで、ほとんどの人は A で足ります。

A — 何もしない（おすすめ）

設定を済ませたリポジトリ（プロジェクトのフォルダ）を Claude Code で開くだけで、自動で入ります。surprise-pages はその 1 つです。

  • 初回だけ「このフォルダを信頼しますか」と 1 回聞かれる
  • あとは待つだけ。入力するコマンドは無い
B — 自分の手元に入れる

どのフォルダで開いても使えるようにしたいときは、Claude Code の中で 2 行打ちます。1 回やれば以後ずっと有効です。

  • 1 行目で部品の置き場を教える
  • 2 行目でその中の 1 つを入れる

B のときに打つ 2 行は、これです。行の先頭のスラッシュまで含めてそのまま入力します。

Claude Code の入力欄に打つ 
# 1. 部品の置き場を登録する
/plugin marketplace add example-org/surprise-plugins

# 2. ページを作る部品を入れる
/plugin install surprise-pages@surprise-plugins

入ったかどうかは /plugin と打って一覧に出てくるかで確かめられます。あとは、こう話しかけるだけです。

こう言えば動きます

「この調査結果をページにして」

手元のメモや検索結果を 1 枚にまとめる

「新しい申請の流れを図解して社内に共有して」

手順を図に起こして社内限定で投稿する

「今日の議事録をまとめてページにして」

決まったこと・担当・期限をカードに分けて出す

「このページを消して」

作ったページを取り下げる。消したい URL を伝える

社外に見せたいときは、そう言う

何も言わなければ必ず社内限定で投稿されます。門なしの公開ページにするのは、「社外にも見せたい」「公開ページにして」とあなたがはっきり伝えたときだけです。うっかり公開されることはありません。

コメントの使い方

コメントはどのページにも最初から付いています。作った人が何か設定する必要はありません。使い方は文書共有サービスの感覚とほぼ同じで、気になった文章をドラッグで選んで、その場に書くだけです。

2 歩目で出てくる小窓と、3 歩目の入力欄は、こんな見た目です。

新しい申請の流れは、まず担当者が下書きを作り、部門長の承認を経てから経理に回ります。承認が下りるまでの目安は 3 営業日です。

コメント

部門長が不在のときの代理承認も書いておきたいです

真ん中に並んでいる 3 つの丸いボタンが「どのくらい直してほしいか」です。読む側が対応の順番を決めやすくなるので、必ず 1 つ選びます。

must

必ず直す。事実が違う、このままでは困る、というとき

better

直したほうがよい。間違いではないが、もっと良くなるとき

want

できれば。好みの提案や、余力があればという要望

書いたコメントには返信ができ、対応が終わったら解決にできます。解決したものは畳まれて下がるので、まだ手が要るものが埋もれません。コメント 1 件ごとのリンクもカードから取れるので、「ここ見てください」と直接その位置を送れます。

誰が書けるか

ページの種類 読む 書く
社内限定 会社の人だけ 会社の人だけ
公開 誰でも 会社の人／名前を入れた社外の方

公開ページで社外の方がコメントしようとすると、名前を 1 つだけ聞かれます。メールアドレスも会員登録も要りません。一度入れれば、次に同じブラウザで開いたときも同じ人として扱われ、自分のコメントだけ直したり消したりできます。会社の人はログインしていれば普段の名前と顔で書けるので、名前を聞かれることはありません。

コメントの一覧を開いたり、他の道具を出したりするのは、画面の右下に出る道具箱からです。このページの右下にも出ています。

履歴

コメント — 右側の一覧を開け閉めする。未解決だけに絞る、書き出す、もここから
履歴 — いつ誰が直したかの一覧。版を選ぶと 1 つ前との違いが出る
リンクをコピー — このページの URL を写す

本文を直してもコメントは迷子にならない

ページの本文を書き直しても、引用した文言が残っていれば下線は付き直します。文言ごと消えた場合は下線が消えるだけで、コメント自体は一覧に残ります。「直したらコメントが全部飛んだ」ということは起きません。

社内限定と公開の違い・気をつけること

ページには 2 つの置き場所しかありません。入口に門があるか、無いかの違いです。URL を見れば、どちらなのかがすぐ分かります。

社内限定（既定）
pages.example.com/i/...
  • 会社の Google アカウントで入った人だけが開ける
  • ページに載せた画像も、毎回ログインを確かめてから渡す
  • Slack にリンクを貼っても、見出しや要約が展開されない
議事録・社内の調査・手順書など、ほとんどはこちら
公開（明示したときだけ）
pages.example.com/p/...
  • 門が無い。URL を知っていれば社外の誰でも開ける
  • 検索には出さない設定だが、リンクが回れば読まれる
  • 社外の方も、名前を 1 つ入れればコメントできる
社外の方に渡す資料など、見せてよいと判断したものだけ

社内限定のページを社外の人に渡したくなったときは、公開ページとして投稿し直す必要があります。あとから門だけ外すことはできません。逆に言えば、間違えて社内のものが公開側に出ることも起きにくくしてあります。

給与・個人情報は上げない

ページを消せば URL は開けなくなりますが、文章そのものは記録として残り続けます。書き直しの履歴を残す仕組みが、同時に「消しても遡れる」性質を持っているためです。

判断の目安: 「あとから無かったことにしたい」と少しでも思うものは、そもそも投稿しない。給与・評価・健康状態・個人を特定できる情報がこれにあたります。

まとめ — 覚えておきたい 3 つのこと

最後に、このページで伝えたかったことを 3 つに絞ってまとめます。

01

作り方は「話しかける」だけ

設定済みのフォルダを開けば自動で使えるようになります。あとは「これをページにして」と伝えるだけで、図つきの 1 枚が組み上がり、URL が返ってきます。

02

読む人は、その場に書き込める

気になった文章を選んでコメントし、強さ（must / better / want）を添えて送る。返信も解決もでき、直した履歴も自動で残ります。感想を集める場所を別に用意しなくて済みます。

03

既定は社内限定。公開は言ったときだけ

何も言わなければ、会社の人しか開けないページになります。門を外すのは、社外に見せてよいと判断してはっきり伝えたときだけ。ただし、消しても文章は記録に残るので、個人情報や給与は最初から載せません。

まずは 1 枚、作ってみてください。

共有したいけれど資料にするほどでもない、と思っていたものが向いています。調べたこと、決まったこと、後任に引き継ぎたい手順。「これをページにして」と伝えるところから始まります。
