# コメントとスライド編集の役割分離

大きな画面処理を役割で分け、既存の保存方式と画面操作を保ったまま、変更の影響を追いやすくした。

## コメントの道具箱

| 役割 | 自分で管理するもの |
| --- | --- |
| 共有と閲覧許可 | 投稿先、共有文、許可一覧、確認中の行き先、コピー完了の待ち時間 |
| 原稿の更新 | 原稿の鮮度、取り込み状況、監視と案内の待ち時間 |
| 履歴と比較 | 版一覧、比較中の2版、変更位置の監視、比較の上帯 |
| コメント一覧と送信 | コメント、結果の照合、絞り込み、並び順、編集・返信・送信時の控え |
| 引用と入力操作 | 引用位置、選択範囲、小窓、画面下の入力欄、指の操作と描画待ち |

入口は起動、権限の応答、機能同士の接続、共通の画面枠、終了を担当する。
各機能には必要な項目だけを渡す。入口の状態は各機能の状態へつながる読み書きの窓であり、別の正本ではない。
相互に呼ぶ操作は実行時に取り出し、起動順によって未準備の機能を読み出さない。

終了時に操作の監視、待ち時間、繰り返し、次の描画を解除する。ブラウザが戻る操作のため画面を保持するときは解除せず、戻ったあとも既存の操作を使える。
終了後の通信結果は採らない。同じ2版の比較を続けて開いた場合も、応答は開いたときの比較自身にだけ適用する。
原稿取り込みの監視も、開始時に控えた取り込みと現在の取り込みが同じときだけ結果を採る。

## スライド編集

| 役割 | 担当する操作 |
| --- | --- |
| 一覧と中央表示 | 枚の選択・並べ替え、縮小表示、拡大率、ノート、下部の表示 |
| 対象の調整 | 文字、配置、画像、動画、図形、切り抜きの調整 |
| 表とグラフ | 内容の入力、貼り付け、検査、既存の変更操作への変換 |
| デザイン | 配色、焦点の段階、ロゴ、資料全体と枚ごとの設定 |
| メニューと確認画面 | 挿入、構図の選択、資料と枚の操作、焦点の移動と復帰 |

編集画面全体は現在の枚、選択、原稿の読み取り、各領域の接続を担当する。
本文の変更は既存の変更操作と保存経路を使う。選択や保存通知だけで本文を作り直さない。
閉じるときは縮小表示、画面幅の監視、メニュー、確認画面、残った待ち時間を解除する。

## 検査

従来の構造検査は、入口からつながっている分割先も1度ずつ読む。分割先の外側についた字下げだけを揃え、移動前の関数単位の検査を維持する。
機能間の接続は、実際の道具箱を載せた操作検査とブラウザ操作で確認する。
新しい14項目は、終了後の待機・監視の解除、逆順の比較応答、閉じたあとに届く応答、別画面へ移ったあとの失敗応答、分割先の検査範囲を確認する。

```sh
pnpm verify
node tests/checks/browser/deck-editor-continuity.mjs
node tests/checks/browser/deck-workspace-features.mjs
```

追加の画面検査は、それぞれが一時的な保存先と手元のサーバーを起動する。社内の保存先へ接続しない。
ブラウザの検査に使う道具の場所は環境変数で指定できる。

```sh
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs node tests/checks/browser/deck-workspace-features.mjs
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs DECK_BROWSER=webkit node tests/checks/browser/deck-editor-continuity.mjs
```

通信の項目、権限判定、本文の形式、版と受領記録、非公開の素材保管は変更していない。
